# BankTrap

Локальный стенд: банковская приманка → событие атаки → правило → проверка → блокировка и откат.

## Запуск

Python 3.10+, без внешних зависимостей.

```bash
python3 app.py
```

Откройте **http://127.0.0.1:8765**, вставьте токен из терминала в «Доступ оператора» и подключите SOC. На Windows: `py -3 app.py`.

## Тесты

```bash
python3 -m unittest -v test_app.py
```

[Видео демо](docs/demo.mp4) · [Скриншоты](docs/SCREENSHOTS.md) · [Подробности и ограничения](docs/REFERENCE.md)

Прототип работает с вымышленными данными. Правило действует только в тестовом шлюзе; подключения к банковским системам нет.
