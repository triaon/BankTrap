# Проверка локального MVP

Выполнено 31.10.2026 на macOS, Python 3.14, Google Chrome (headless).

Три интеграционных теста прошли:

- Полный HTTP-цикл: до правила → событие → кандидат → replay → включение → блокировка → обычный запрос → откат → сброс.
- Границы управления: токен, Host/Origin, размер и тип ввода, перевод без входа.
- Классификация: открытая админка без T1078, пять неудачных попыток, синтетическая учётная запись, имитированный перевод.

Дополнительно браузер автоматически прошёл основной сценарий кнопками, скачал JSON-пакет, проверил откат. Ошибок JavaScript не обнаружено. При ширине 390 px горизонтального переполнения нет. Проверено визуальное отображение интерфейса на desktop.

Результат на открытом acceptance-наборе: TP=8, FN=0, FP=0, TN=12. Отдельные известные ограничения: AND-based SQLi и time-based SQLi не блокируются; строка `union select`, введённая как легитимный логин, блокируется. Эти случаи намеренно сохранены в `corpus.json` и не скрываются за результатом acceptance.

Проверка подтверждает работу демонстрационного цикла. Она не подтверждает качество на трафике банка, устойчивость к нагрузке, отсутствие всех уязвимостей, полноту SQLi-детектора или совместимость с реальным WAF. Нагрузочное испытание и банковский пилот не проводились.

Светлая версия интерфейса: повторно проверены вход по Enter, создание и проверка правила, включение, обычный запрос, экспорт и откат. При ширине 390 px страница не имеет горизонтального переполнения; журнал прокручивается отдельно. Ошибок JavaScript не обнаружено.
